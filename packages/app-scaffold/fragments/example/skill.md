# Example fragment

A placeholder fragment shipped with the Roomy app scaffold. It demonstrates
the standalone-fragment shape (single root component, mounted at `#root`)
without doing anything useful.

## Behavior

- Shows a "Clicked N times" button and a Reset button.
- All state is local React state — no Roomy API calls.

## Capabilities

None. This fragment doesn't talk to the Roomy API.

## Storage contract

This fragment does not use persistent app storage. It has no collections,
document shapes, or supported agent CRUD operations.

When replacing this placeholder with a real storage-backed fragment,
document the fragment's contract here before shipping it:

- Required capabilities: `storage.read`, `storage.write`, or both.
- Collections used.
- Document shape for each collection.
- ID strategy: generated by `create` or app-chosen with `put`.
- Allowed agent CRUD operations.
- Validation rules, invariants, and example records.

## When to replace

Always — this fragment exists only as the starting point. Delete the
directory or replace its contents with the real UI when you author a
fragment for a user request.
