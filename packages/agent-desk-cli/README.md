# @agent-desk/cli

Host CLI for Desk — boots the full server stack locally.

## Usage

```sh
npx @agent-desk/cli@alpha
```

Opens the Desk UI at `http://127.0.0.1:35138/` and keeps it running in the foreground.

## Requirements

- Node.js ≥ 23.4.0
- Docker (for the sandboxed agent runtime)
